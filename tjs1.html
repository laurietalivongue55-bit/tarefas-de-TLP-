Introdução ao JavaScript

O JavaScript é uma linguagem de programação essencial para o desenvolvimento web. Ele permite adicionar interatividade às páginas, manipular elementos HTML e CSS, e criar aplicações dinâmicas.

Principais características:

  • Executa diretamente nos navegadores.
  • Permite manipular o conteúdo da página em tempo real.
  • É usado junto com HTML e CSS para criar sites modernos.
  • Suporta programação orientada a objetos e funções.

Exemplo simples:


<button onclick="alert('Olá, este é JavaScript!')">
  Clique aqui
</button>

No exemplo acima, ao clicar no botão, o JavaScript executa uma função que mostra uma mensagem na tela.

Variaveis São usadas para armazenar valores. Podem ser declaradas com var, let ou const. let → variável que pode mudar. const → valor fixo, não pode ser alterado. Tipos de dados Principais tipos: string (texto) number (números) boolean (verdadeiro/falso) object (coleção de dados) array (lista ordenada) null e undefined (ausência de valor).

Operadores Aritméticos: +, -, *, /. Comparação: ==, ===, >, <. Lógicos: &&, ||, !.

Estruturas de controle Controlam o fluxo do programa: if...else switch for, while, do...while.
