Introdução ao CSS

O CSS (Cascading Style Sheets) é a linguagem usada para estilizar páginas web. Ele permite controlar cores, fontes, espaçamentos, tamanhos e até animações. Enquanto o HTML organiza o conteúdo, o CSS dá vida e aparência a esse conteúdo.
